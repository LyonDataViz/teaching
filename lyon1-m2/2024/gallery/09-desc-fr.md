# Analyse des Données Personnelles de l'Application Santé

## But du Projet
Ce projet a pour objectif d'analyser et de comparer les données personnelles collectées via l'application Santé des iPhones des membres de notre groupe. Nous souhaitons mieux comprendre leurs habitudes en matière d'activité physique, de sommeil et de bien-être à travers des visualisations interactives et un storytelling engageant.

### Questions Guidantes
Nous explorons les questions suivantes :  
1. Comment l’activité physique varie-t-elle entre les membres du groupe ?  
2. Comment les cycles de sommeil diffèrent-ils entre les membres du groupe ?  
3. Les niveaux d’activité influencent-ils la qualité du sommeil ?  
4. Comment les comportements de santé évoluent-ils sur une semaine ou un mois ?  

## Visualisations Principales
Six visualisations ont été développées pour permettre une analyse détaillée :  

1. **Line Chart : Comparaison des pas**  
   Compare le nombre de pas effectués par les utilisateurs d'année en année. L'année peut être changée via des boutons interactifs.  

2. **Bubble Chart : Analyse de la distance parcourue**  
   Montre la relation entre la distance parcourue et les calories brûlées, avec une vue segmentée par année.  

3. **Line Chart : Analyse des calories brûlées**  
   Affiche l'évolution des calories brûlées par mois, avec une option pour modifier l'année.  

4. **Bar Chart : Comparatif des heures de sommeil**  
   Représente le nombre d'heures de sommeil par mois. En cliquant sur une barre, un graphique détaillant les jours du mois s'affiche.  

5. **Bubble Chart : Nombre d'heures de sommeil**  
   Visualise le lien entre le nombre d'heures de sommeil et les pas parcourus chaque semaine.  

6. **Graphique Radial : Distances et sommeil**  
   Présente les distances parcourues et les heures de sommeil sous forme radiale pour chaque semaine.  

## Fonctionnalités Dynamiques
Les visualisations s'adaptent dynamiquement lorsqu'un utilisateur change d'année à l'aide des boutons. Cela garantit une expérience fluide et un storytelling cohérent, avec des descriptions adaptées à chaque visualisation.
